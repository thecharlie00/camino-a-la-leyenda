# Fuentes

`files/` contiene solo los `.woff2` que usan `build.py` y `build_web.py`:

- **Atkinson Hyperlegible Next** 400, 500, 700 y 800 (latín y latín extendido).
- **Pixelify Sans** 500 y 700 (latín y latín extendido), usada como `CamDisp`.

Se copiaron de los paquetes `@fontsource/atkinson-hyperlegible-next@5.3.0` y
`@fontsource/pixelify-sans@5.2.6`. Las licencias OFL están en este mismo directorio.

No hace falta instalar dependencias para compilar: los archivos se guardan aquí
para que el build funcione sin conexión.
